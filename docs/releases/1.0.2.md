# shim-cli 1.0.2

Claude Code loads one hook file from the plugin instead of two. The Codex hook
file moved to `hooks/codex.json`, named by `.codex-plugin/plugin.json`, so Claude
Code no longer finds it by convention and no longer runs a Codex command on every
prompt only for it to stand down. Nothing you see in Claude Code changes.

Codex users: current Codex installs the plugin but does not load its hook, so the
plugin has not been inspecting your prompts, and Codex does not say so. Remove it
and install the hook instead, then trust the shim entry in `/hooks`:

```console
codex plugin remove shim-cli@shim-cli
shim install codex
shim doctor codex
```

The PyPI page now says what the README says: its summary is the tagline, it has
search keywords, its homepage is
[getshim.tech/products/shim-cli](https://getshim.tech/products/shim-cli), and it
links to these release notes.

The plugin folder carries its own `LICENSE`, so an installed copy of the plugin
includes the Apache-2.0 text.
